# Photos go here 🌸

The landing page looks for these files. Until you add them, the page shows a
tasteful placeholder pattern in each slot — nothing breaks.

| File name        | Used for                                   | Best aspect ratio |
|------------------|--------------------------------------------|-------------------|
| `gallery-1.jpg`  | Hero image **and** first (tall) gallery tile | portrait 4:5      |
| `gallery-2.jpg`  | Gallery — table décor / characters         | landscape/square  |
| `gallery-3.jpg`  | Gallery — themed corner / globe            | landscape/square  |
| `gallery-4.jpg`  | Gallery — centerpiece (tall tile)          | portrait 4:5      |
| `gallery-5.jpg`  | Gallery — gift / couple characters         | landscape/square  |

## How to add them
1. Rename your photos to the names above (`.jpg` or change the extension in
   `index.html`).
2. Drop them into this folder (`assets/images/`).
3. Commit & push — the page picks them up automatically.

Tip: keep each image under ~400&nbsp;KB for fast loading (resize to ~1600px on
the long edge).
